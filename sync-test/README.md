# Штаб Офлайн — тестовая синхронизация 0.2-pre

**Внимание: только вымышленные дела и отдельная тестовая Google Sheets.**

Для работы понадобятся URL отдельного Apps Script `/exec` и 64-символьный тестовый секрет, сгенерированный `setupTestSync()` **в тестовой таблице**. Секрет нельзя размещать в GitHub или пересылать кому-либо.

Тестовая таблица: https://docs.google.com/spreadsheets/d/1BW68gb2l5HxcHZ0Fn-BAM91XZCPyQ-QOijRaCibQ9as/edit

Подробная инструкция установки сервера: [`ИНСТРУКЦИЯ_УСТАНОВКИ.md`](../docs/ИНСТРУКЦИЯ_УСТАНОВКИ.md)

Поля задачи и заседаний изменяются локально в IndexedDB и попадают в очередь. При наличии связи приложение отправляет операции в ограниченный Apps Script и проверяет подтверждение через ID операции. Если возник конфликт, удаление очереди запрещено до решения пользователем.

Транспорт использует JSONP и скрытую форму: это проверяемый прототип, а не готовый продуктивный канал для конфиденциальной юридической базы. Реальный запуск на Safari/iPhone с сервером ещё не испытан.
