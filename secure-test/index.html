Офлайн-сейф

Только просмотр тестовой CRM. Зашифрованная копия хранится на этом устройстве; без сети для открытия нужен отдельный пароль.

Проверка готовности к офлайн-работе…

1. Загрузить зашифрованную копию

Сначала добавь эту страницу на экран «Домой» из Safari, затем импортируй файл именно из установленного приложения. Его хранилище отделено от обычной вкладки Safari.

2. Разблокировать данные

Если пароль утерян, восстановить данные из шифротекста нельзя. Сохрани зашифрованный файл в «Файлах» отдельно.

Тестовые данные

Офлайн-копия может устареть. Для актуальных сроков сверяйся с основной CRM. Запись и синхронизация отключены.

Данные не загружены.
