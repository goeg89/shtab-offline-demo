ШТАБ ОФЛАЙН — первый безопасный прототип v0.1-pre
==================================================

НАЗНАЧЕНИЕ
Это отдельное демонстрационное приложение. В нём используются только
ВЫМЫШЛЕННЫЕ дела. Оно не подключается к реальной Google Sheets CRM.
Записывать здесь сведения настоящих клиентов пока НЕЛЬЗЯ.

ЧТО УЖЕ РАБОТАЕТ
- Локальное хранение карточек дел и заседаний (IndexedDB).
- Сохранение изменения задачи, планового срока и юридического срока.
- Фиксация результата заседания и следующего заседания одновременно
  с изменением текущей задачи.
- Очередь несинхронизированных действий с уникальными ID.
- Фокус на сегодня и выбор дел вручную.
- Экспорт/импорт резервной копии демонстрации в JSON.
- Автономная загрузка после первого успешного открытия
  на HTTPS-сайте либо localhost (Service Worker).

ЧЕГО ПОКА НЕТ
- Синхронизации с Google Sheets: пока НИ ОДНА операция не отправляется.
- Авторизации, шифрования локальной базы и защиты для персональных данных.
- Реального серверного разрешения конфликтов, XP и серверных журналов.
- Гарантированной синхронизации в фоне при закрытом iPhone-приложении.

ПРОВЕРКА НА КОМПЬЮТЕРЕ (Windows)
1. Распакуй ZIP в отдельную папку.
2. Открой в этой папке Windows PowerShell.
3. Выполни: py -m http.server 8000
   Если команда py не работает: python -m http.server 8000
4. Открой в Chrome: http://localhost:8000
5. Открой дело «Иванов И.И. (пример)».
6. Запиши результат заседания, следующее заседание и новую задачу;
   нажми «Сохранить на устройстве».
7. Проверь «Очередь изменений»: должна появиться одна операция.
8. В Chrome нажми F12 → Network → Offline, затем обнови страницу.
   Приложение должно открыться; очередь и задача должны остаться.
9. Отключи Offline и экспортируй резервную копию из очереди.

ВАЖНО: просто двойной щелчок по index.html (file://) не подходит для
тестирования Service Worker. Нужен HTTPS или http://localhost.

НА IPHONE (нужен HTTPS-сайт)
1. Размести содержимое этого архива на ОТДЕЛЬНОМ HTTPS-сайте,
   например GitHub Pages в новом репозитории. НЕ загружай сюда реальные
   клиентские сведения. Содержимое архива (HTML/JS/CSS) статическое.
2. Открой HTTPS-адрес в Safari на iPhone при наличии интернета.
3. Нажми «Поделиться» → «На экран Домой».
4. Открой установленное приложение хотя бы один раз с интернетом,
   чтобы браузер сохранил оболочку приложения.
5. Включи авиарежим и отключи Wi-Fi.
6. Полностью закрой приложение, затем открой его с домашнего экрана.
7. Измени любую ДЕМО-задачу и проверь увеличение счётчика очереди.
8. Закрой и снова открой приложение без сети: изменение должно остаться.
9. Восстанови интернет: изменения всё равно остаются в очереди,
   поскольку тестовый сервер синхронизации пока НЕ подключён.

КАК РАЗМЕСТИТЬ НА GITHUB PAGES
- Создай отдельный публичный репозиторий, например shtab-offline-demo.
- В нём нажми Add file → Upload files и загрузите ФАЙЛЫ и папку icons
  из распакованного архива (а не ZIP-файл).
- Перейди Settings → Pages → Build and deployment → Deploy from a branch.
- Выбери main и / (root), сохрани.
- После публикации GitHub покажет HTTPS-адрес нового приложения.
- Код публичного демопроекта не содержит настоящих дел или паролей.

ПРЕДУПРЕЖДЕНИЕ
Данные браузера могут быть удалены системой, при очистке сайта или
нехватке места. Не полагайся только на локальную копию. В демоверсии
используй функцию «Сохранить резервную копию».

ДАЛЬШЕ
Когда подтвердим офлайн-сохранение на iPhone, добавим защищённый сервер
синхронизации с ТЕСТОВОЙ Google Sheets, проверим конфликты и защиту XP.
Рабочий Apps Script / опубликованный Web App пока не трогаем.
