# Штаб Офлайн — демонстрация 0.1-pre

**Тестовый PWA без подключения к Google Sheets.** Все клиенты, дела и заседания в нём вымышлены.

## Как открыть на iPhone

1. Открой **Settings → Pages** этого репозитория: https://github.com/goeg89/shtab-offline-demo/settings/pages
2. В **Build and deployment** выбери **Deploy from a branch**.
3. Установи **Branch: main**, **Folder: / (root)**, нажми **Save**.
4. После публикации открой адрес: https://goeg89.github.io/shtab-offline-demo/ (до публикации он может не открываться).
5. В Safari нажми **Поделиться → На экран «Домой»**. Открой приложение один раз с интернетом.
6. Включи авиарежим и отключи Wi-Fi, закрой и заново открой приложение. Проверь изменение вымышленного дела и счётчик очереди.

## Что делает

- Показывает демонстрационные задачи и заседания из локальной IndexedDB.
- Позволяет менять задачи, сроки и результаты заседаний без сети.
- Хранит отдельную очередь операций; позволяет скачать/восстановить резервную копию.
- Service Worker сохраняет локальные файлы приложения после первого успешного открытия.

## Важно

**Это не действующая CRM.** Синхронизации с Google Sheets нет. Никакие действия из демонстрационного приложения не отправляются в рабочую таблицу. Не вводи настоящих клиентов, судебные документы или персональные данные. Используй только тестовые записи.

При очистке данных Safari, удалении приложения или вытеснении IndexedDB данные могут быть потеряны. Пока не готова защищённая серверная синхронизация, «Сохранено на устройстве» не означает «Сохранено в Google Sheets».

Состав тестового комплекта и архитектуру последующей защищённой синхронизации см. в файлах [НАЧАТЬ_ЗДЕСЬ.txt](./НАЧАТЬ_ЗДЕСЬ.txt) и [АРХИТЕКТУРА_СИНХРОНИЗАЦИИ.md](./АРХИТЕКТУРА_СИНХРОНИЗАЦИИ.md).
