Мои дела · отдельный тест 0.9.3

Офлайн-правки

Дела и заседания из тестовой копии. Изменения остаются зашифрованными в хранилище этого устройства. Никакой записи в Google Sheets или автоматической синхронизации.

Проверка офлайн-оболочки…

1. Импорт копии для правок

Нужен новый файл, полученный кнопкой «Подготовить офлайн-копию для локальных правок (0.9)». Файл версии 0.8 подходит только для просмотра в старом приложении.

Сначала добавь этот новый адрес на экран «Домой», затем выполняй импорт из приложения с новой иконки. Шифротекст хранится в хранилище именно этого приложения.

2. Разблокировать

Храни отдельно исходный зашифрованный файл и резервные копии зашифрованного журнала. При очистке данных iPhone хранилище приложения может исчезнуть.

Тестовые данные

Доступ на доверенном устройстве

На личном телефоне или компьютере можно один раз ввести фразу и разрешить этому браузеру открывать дела и сохранять локальные правки без дальнейшего ввода. При этом сохраняется неэкспортируемый ключ в хранилище этого сайта. Это не Google-вход: Google нужен для получения новой копии на сервере, а офлайн-приложение работает независимо.

В режиме полного доверия доступ к разблокированному устройству, браузерному профилю или коду этого сайта может означать доступ и к данным, и к редактированию. Не включай на чужом или общем устройстве. Данные остаются на устройстве; записи в Google Sheets по-прежнему нет.

Включён режим только просмотра. Для редактирования требуется исходная парольная фраза. Для полного доверия сначала разблокируй редактирование фразой, затем включи разрешение выше.

Разрешить редактирование

Это снимок на момент экспорта. Правки НЕ отправляются в CRM. Юридические сроки остаются только для чтения. Перед будущим применением потребуется сверка исходных значений и разрешение конфликтов.

Нажми на карточку дела или на кнопку «Изменить задачу и плановый срок». Для дел без строки на листе «Список» доступен только просмотр.

Зашифрованный журнал изменений

В журнале хранятся исходное значение, новое значение, идентификатор записи и время правки. Он зашифрован той же парольной фразой и привязан к этому снимку. Не содержит команд записи на сервер.

Разные поля одного дела объединяются: например, задача с iPhone и плановый срок с компьютера сохранятся вместе. Если изменено одно поле, сохранится значение с более поздней отметкой времени. При одинаковом времени и разных значениях остаётся локальное. Проверь, что дата и время на устройствах выставлены автоматически. Журнал переносится файлом вручную: обмен между устройствами и отправка в Google Sheets пока не реализованы.

Локальная правка

Сохраняется только зашифрованный локальный черновик. Исходная CRM и юридический срок не изменяются.
